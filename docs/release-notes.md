# MATLAB AI 助手 · 首个测试版

在 MATLAB 中生成、解释、修改和续写代码，查看差异后直接应用到编辑器。支持本地对话历史、函数帮助和部分 Simulink 修改。

下载 `matlab-ai-bridge-v0.1.0-beta.1.zip`，解压后在 MATLAB 中运行 `start_ai.m`，按首次配置向导完成设置。

需要 Windows、MATLAB R2026a、Python 3.11+，以及已安装并配置账户的 Agent CLI。ZIP 不包含这些依赖。

- Codex 已验证真实模型请求及编辑流程。
- Claude Code 尚未验证成功生成；DeepSeek Harness 为实验适配。
- 生成代码不会自动保存或运行。模型连接测试可能产生用量。
