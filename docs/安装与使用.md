# 安装、首次配置与日常使用

本文面向使用者。希望让自己的 AI 帮忙配置，请把项目目录和 [AI_SETUP.md](../AI_SETUP.md) 交给它。
项目路径、Python 路径、Agent 路径和模型 ID 都以使用者本机为准，不要复制作者电脑的路径。

## 1. 准备环境

目前桌面向导的支持与验证范围是 **Windows + MATLAB R2026a**。macOS、Linux 和旧版 MATLAB 尚未适配此向导；Python 配置脚本可运行不代表完整 MATLAB 应用跨平台可用。

需要：

- 已安装且能正常打开的 MATLAB。
- Python **3.11 或更高版本**。后端只用标准库，在 MATLAB 内启动不需要 `pip install`，也不需要 MATLAB Engine for Python。
- 至少一个受支持的 Agent CLI，安装在当前用户能够启动的位置。只有桌面聊天应用不保证存在 CLI。
- 该 Agent 已配置好自己的账户、模型权限及必要网络环境。
- 可写的项目目录，用于保存 `config.local.json`、历史和输出。

| 后端 | 配置值 | 模型填写方式 | 当前验证范围 |
| --- | --- | --- | --- |
| Codex CLI | `codex` | 本机 Codex 配置提供候选，也可填自己可调用的模型 ID | 已验证真实模型请求与编辑器流程 |
| Claude Code | `claude` | 留空使用 CLI 默认模型，或填写可用模型 ID | 已验证 CLI 初始化与适配协议；本机未完成登录，未验证成功生成 |
| DeepSeek Harness | `deepseek_harness` | 必须填写模型 ID | 实验性；协议模拟测试通过，尚未验证真实安装和模型请求 |

“DeepSeek 模型”不等于“DeepSeek Harness”。如果你通过 Codex CLI 的已配置提供商调用 DeepSeek 模型，Agent 仍选择 **Codex**。
账户登录、API Key 或代理由相应 Agent 的官方配置方式管理；本项目没有统一登录系统。
DSH 当前使用 `DEEPSEEK_API_KEY`，可选 `DEEPSEEK_BASE_URL`；MATLAB 需要从启动时的环境中继承这些设置。
若更改了系统环境变量或安装目录，关闭并重新打开 MATLAB 后再检测。

## 2. 首次启动

![首次配置向导，图中的程序路径和模型名称仅为示意](images/setup-wizard.png)

1. 下载项目并解压到自己的可写目录，保留 `start_ai.m`、`matlab/`、`backend/` 与 `setup_cli.py` 的相对位置。
2. 在 MATLAB 中打开项目根目录的 **`start_ai.m`**，点击“运行”。也可在 MATLAB 命令窗口执行：

   ```matlab
   run('D:/你的项目目录/matlab-ai-bridge/start_ai.m')
   ```

3. 没有 `config.local.json`、配置无法解析、Python 路径失效，或需要的模型 ID 缺失时，会打开“首次配置向导”。未完成配置时不会启动助手请求。
4. 点击 **检测环境**。Python 留空时，向导查找当前 MATLAB 的 Python 设置、PATH、用户常见 Python 安装目录；找不到时，点击“选择 Python”选择真正的 `python.exe`。
5. 确认要使用的 Agent。检测范围是 PATH 和常见用户安装位置；不会扫描全盘，也不会自动安装或登录。找不到 Agent 时，安装后重试，或者手动选择它的程序文件。
6. 核对 Agent 路径及模型 ID。支持原生程序和 `.js/.mjs/.cjs` 入口；JS 入口需要 Node.js，必要时填写 Node 的绝对路径。向导会把可识别的 npm 包装入口转换成真实程序或 JS 入口；不执行任意 `.cmd/.ps1` 脚本。
7. 设置等待时间，然后点击 **保存配置**。新配置默认首次 120 秒、回答中断 90 秒、整次请求 600 秒。总时间必须大于等于其他已启用的时限；首次/中断填 0 可关闭对应限制。
8. 可点击 **检查安装（不调用模型）**；需要验证登录、网络和模型权限时，点击 **测试模型连接（可能产生用量）**。
9. 点击 **完成**。从首次启动进入的向导会打开助手。若是用 `matlab_ai_setup` 单独打开的向导，“完成”只关闭向导，再运行 `start_ai.m` 即可。

检测、保存和检查安装都不生成模型回答。只有点击真实模型测试，才发送固定的 `disp(1)` 示例；不读取编辑器或项目代码。
检测会启动候选程序的 `--version`，请只选择自己信任的程序文件。
等待期间可以取消当前操作。保存成功后的配置会保留；关闭向导不会自动保存表单中的后续修改。

## 3. 如何判断配置成功

| 结果 | 已验证 | 尚未验证 |
| --- | --- | --- |
| 检测到程序 | Python 能启动，检测到的 Agent 能返回版本 | 登录、额度、模型权限、网络 |
| 配置已保存 | 所选程序可启动、模型字段和等待值合法，项目配置已写入 | 真实模型调用 |
| 安装检查通过 | 配置能读取，Python 版本和 Agent 启动检查通过 | 真实模型调用 |
| 真实模型连接成功 | 固定示例请求完成，响应通过本项目格式校验 | 其他模型、所有任务及其他电脑的兼容性 |

CLI 的版本检查只能证明程序可启动，不能证明它支持本项目所需的全部协议。
真实测试失败时会显示错误原因，不会回退到另一个 Agent，也不会把“安装检查通过”当成“模型连接成功”。

## 4. 日常使用与重新配置

再次运行 `start_ai.m`，已有配置可用时直接打开助手。项目不会自动给其他用户创建桌面图标或安装 MATLAB 启动项。

新建代码：选择“需求生成”，输入需求，发送后查看生成代码；点击“新建代码文档”，或先预览光标插入再确认。
修改现有代码：在编辑器打开 `.m` 文件，选择解释、修改或续写，核对范围后发送；查看差异再应用。
助手不会自动保存或执行模型生成的代码；更多功能和限制见 [功能参考](功能参考.md)。

只改 Agent、模型或等待时间：使用助手内的“后端与等待设置”，保存后供下一次请求使用。
更换 Python、项目迁移或需要重新检测环境：先关闭助手窗口，在 MATLAB 运行：

```matlab
addpath('D:/你的项目目录/matlab-ai-bridge/matlab')
matlab_ai_setup
```

保存后重新运行 `start_ai.m`。已有助手实例不会自动读取另一个窗口写入的配置。
旧配置无需强制迁移，也不会因为添加向导而重置等待时间。向导更新已有配置时会保留未修改的其他字段，备份原文件到 `output/setup-backups/`。
损坏的 JSON 会阻止保存，请先备份并修复；不要直接删除仍需保留的旧配置。

## 5. 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 没找到 Python | 安装 3.11+，选择实际 `python.exe`；WindowsApps 商店别名不作为自动候选 |
| 装了 Agent 但没检测到 | 选择原生可执行文件或 JS 入口；重开 MATLAB 以继承最新 PATH；便携安装需手动定位 |
| JS 入口启动失败 | 检查 Node.js 路径、npm 包文件及其依赖是否完整 |
| 安装通过但模型测试失败 | 根据提示检查登录、模型 ID、权限、额度、代理或网络；安装成功不证明账户可用 |
| CLI 参数未知或协议不兼容 | 核对所选 Agent 版本与 README 的验证范围；不要通过增加超时掩盖版本错误 |
| 首次回答超时 | 调大首次及总等待，保存后重试；纯思考事件不算可显示回答 |
| 总等待小于首次或中断等待 | 调整总等待，或将不需要的分段限制设为 0 |
| 重配后还是旧模型 | 关闭已有助手窗口，重新运行 `start_ai.m` |
| 检测后没自动保存 | 检测只填候选；必须核对字段并点击“保存配置” |
| `config.local.json` 无法解析 | 备份该文件，修复为 JSON 对象；向导不会覆盖损坏文件 |

## 6. 配置文件与分发

配置写在项目根目录的 `config.local.json`。优先通过向导或 `setup_cli.py` 生成；`config.example.json` 只是字段模板，里面的空路径不能直接运行。

| 字段 | 含义 |
| --- | --- |
| `python_executable` | 实际 Python 3.11+ 的绝对路径 |
| `backend` | `codex`、`claude` 或 `deepseek_harness` |
| `codex_executable` / `claude_executable` / `deepseek_harness_executable` | 对应 CLI 的程序或 JS 入口路径；手工留空时在调用时查找 PATH |
| `node_executable` | 可选，JS 入口需要的 Node 路径；留空则查找 PATH |
| `model` | 当前后端模型 ID；Claude 默认模型保存为 `__default__` |
| `backend_models` | 各后端记住的模型 ID，JSON 对象 |
| `first_output_timeout_seconds` | 首个可显示回答等待秒数，0 关闭 |
| `idle_timeout_seconds` | 已开始回答后停止更新的等待秒数，0 关闭 |
| `timeout_seconds` | 整次请求等待秒数，上限 86400；向导允许 1–86400 |
| `setup_version` | 向导/配置脚本写入的配置流程版本，目前为 1；旧配置不要求有该字段 |

不要把 API Key 写入项目配置或提交到仓库。登录凭据仍由 Agent 自己保存。
发布项目时排除 `config.local.json`、临时 `config.local.json.*.tmp` 和整个 `output/`；后者包含本机备份、日志、对话和代码。
`.gitignore` 已排除这些路径，但手动压缩整个文件夹不会自动遵守 `.gitignore`，打包时要自行排除。
外部 `launch_ai.ps1` / `launch_ui.py` 属于可选 Engine 启动方式，需要已完成配置。MATLAB 路径会自动查找，也可向 `launch_ui.py` 传入 `--matlab-root`；首次使用推荐 MATLAB 内运行 `start_ai.m`。
