# 开发与验证

| 路径 | 内容 |
| --- | --- |
| `matlab/` | 原生界面、配置向导、编辑器事务和 Simulink 支持 |
| `backend/` | Agent 适配、流式请求、响应校验 |
| `setup_cli.py` | 环境检测、配置生成和连接检查 |
| `tests/` | Python 测试与独立 MATLAB 测试入口 |
| `integration/` | 可选启动集成 |
| `scripts/build_release.py` | 发布清单检查、ZIP 和 SHA-256 生成 |

## 测试

使用 Python 3.11+，在项目根目录运行：

```powershell
python -B -m unittest discover -s tests -q
```

MATLAB 的界面与编辑器测试位于 `matlab/ai_*test.m`。
`ai_setup_test` 和 `ai_backend_settings_test(false)` 不生成模型回答，使用独立临时配置；前者需要本机已配置 Codex，且模型目录可访问。
带真实模型验证的测试会使用账户用量，执行前阅读对应函数说明。

已在 Windows、MATLAB R2026a Update 5、Python 3.12.14 验证编辑、预览、应用、恢复和 Codex 真实请求。
首次配置流程已验证环境检测、保存、备份、取消后重试、损坏配置保护与新目录启动。
Claude 真实模型生成和 DSH 真实环境仍未完成验收，其他平台和 MATLAB 版本未验证。
历史验证记录见 [验证报告](验证报告.md)；其中 `output/` 报告是开发机器生成的文件，不随发布包分发。

## 打包

```powershell
python -B scripts/build_release.py --version v0.1.0-beta.1
```

生成 `dist/matlab-ai-bridge-<版本>.zip` 和 `.sha256`。脚本只打包列入清单的源码、示例和文档，排除本机配置、运行输出、缓存及 Git 元数据。
ZIP 顶层目录为 `matlab-ai-bridge/`。解压后从 `start_ai.m` 开始。
脚本也会检查仓库内文档链接、敏感文件和明显的凭据格式。发布前仍应审阅实际文件清单。
