# 功能与限制

安装流程见 [安装与使用](安装与使用.md)。

## 编辑代码

“需求生成”只发送问题及启用的最近对话，不读取编辑器。生成后可新建未保存文档，或在当前光标处预览插入。
处理现有 `.m` 文件或未保存文档时，选择解释、修改或续写，并确认范围：

- 解释只返回文字。
- 选区修改只替换捕获的范围，其他代码保持原样。
- 全文修改替换当前文件内容。
- 续写在光标处插入，需要先取消选区。

“逐行差异”可选择接受哪些修改块。应用和恢复均不自动保存或执行代码。
应用前检查目标文档、内容、选区和磁盘状态；若发生变化则拒绝覆盖。
恢复使用最近一次应用的内存快照，关闭助手后不保留；后续编辑或保存可能使恢复失效。这与 MATLAB 自身的撤销不同。

当前不支持 Live Script、App Designer、多光标、多文件修改及自动运行。
单次代码上下文上限为 300000 字符；大文档差异可能退化为整体替换，建议缩小选区。
代码检查使用 MATLAB Code Analyzer，不执行代码；静态检查通过不代表计算结果正确。

## 对话与帮助

启用“继续当前对话”时，后续问题可引用之前生成的代码。最近最多 6 轮、合计 600000 字符传给模型；本地完整历史单独保留。
“新对话”开始新的上下文；“对话与版本”可查看历史和载入旧代码。助手不共享桌面 Agent 的聊天记录。
“查询帮助”可结合本机函数帮助和安装清单回答问题；不读取编辑器代码。“查本机资料”不调用模型。
安装清单不代表许可证一定可用；本机检索也不是完整的语义搜索。

## Simulink

在“Simulink 模型”页读取当前模型或选中模块，再解释或提出修改。
支持部分模块参数、新增模块、普通信号连线，以及 MATLAB Function 模块代码修改。
修改以操作清单预览，确认后应用；不运行模型返回的 MATLAB 脚本，不自动保存或仿真。

模型快照最多 400 个可见模块、300000 字符。不读取工作区变量的值。
不跨引用模型写入，不自动删除已有模块，不修改求解器，不处理物理保守端口、Stateflow 状态图或 MATLAB Function 接口变化。
带自定义回调、Mask 或有效库链接的目标目前只读；恢复连接不保证恢复原来的手工走线路径。
支持的模块与参数名单见 `matlab/ai_simulink_catalog.m`。

## 后端与等待

调用流程为 MATLAB → Python 后台进程 → 所选 Agent → 模型服务。
Codex 从本机 App Server 读取模型目录，失败时使用本地缓存并标明来源。目录存在不代表账户有调用权限。
Claude 使用配置的模型或其默认模型；DeepSeek Harness 当前只适配 `deepseek-official` provider。

| 等待项 | 说明 |
| --- | --- |
| 首次回答 | 从启动到首个可显示回答；0 关闭该限制 |
| 回答中断 | 已开始回答后停止更新的最长时间；0 关闭该限制 |
| 整次请求 | 总时间限制，始终生效 |

纯思考事件不算可显示回答。等待时间不是推理强度；请求进行中使用提交时的配置快照。
连接错误不自动重试。不完整响应不能插入。取消只结束本次请求拥有的后台进程。
Codex 已在 CLI 0.154.0 验证；Claude Code 2.1.270 已验证初始化，但真实请求止于未登录。
DSH 适配基于 `deepseek-harness-sdk-runtime` 协议 `0.0.1`，目前仍需真实环境验收。

## 数据与边界

选区请求只发送选区；全文修改和续写发送当前文件全文。不会自动发送其他文件或整个项目。
AI 子进程禁用文件修改、shell、MCP 等工具；写入由 MATLAB 的确认应用操作完成。
Claude 的内部 `StructuredOutput` 工具仅用于返回结构化结果。
`output/history/` 保存本地对话与代码。`output/jobs/` 保存临时请求，正常结束后清理；异常退出可能留有文件。
`output/logs/` 保存请求结果、耗时和分类错误，不记录问题、代码、完整模型回答或原始认证错误。
Agent 自己的日志和远端数据保留策略由其配置决定。

## 可选外部启动

推荐入口是在 MATLAB 内运行 `start_ai.m`，无需 Python Engine。
外部 `launch_ui.py` 使用 MATLAB 随附 Engine，可传入 `--matlab-root`，也会查找 `MATLAB_ROOT`、PATH、Windows 安装记录和标准安装目录。
`start_matlab.ps1` 需要显式 `-MatlabRoot`。`run_bridge.ps1` 默认从项目配置读取 Python 路径。
启动集成由 `integration/` 管理，普通 ZIP 使用不需要安装它。卸载已安装的集成使用 `uninstall_integration.ps1`，保留用户其他启动内容。
